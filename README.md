# Островок

«Островок» в стиле Dynamic Island для Windows: мягкий пружинистый остров наверху экрана.
Музыка со словами песен, погода, таймеры, скриншоты с распознаванием и переводом текста,
чат с ИИ, буфер обмена, заметки, календарь, уведомления и маленький персонаж, который живёт в пилюле.

Концепция повторяет проект [Atoll](https://github.com/Fuwni/dynamic-island-windows). Код написан с нуля (C# / WPF, .NET 8).

> ⚠️ Проект собран «вслепую»: на машине, где он писался, не было .NET SDK, поэтому **ни разу не компилировался и не запускался**.
> Скорее всего, при первой сборке всплывут мелкие ошибки — пришлите текст ошибки, и я исправлю.

## Сборка

Нужны Windows 10 (2004+) или 11 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```
build.bat
```

Или вручную:

```
dotnet run -c Release
dotnet publish -c Release -r win-x64 --self-contained true -o publish
```

Не хотите ставить SDK — залейте папку в репозиторий GitHub: workflow `.github/workflows/build.yml` соберёт
готовый ZIP (вкладка **Actions → Artifacts**).

Для вкладки «Чат» нужен [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (в Windows 11 уже есть).

## Что умеет

| | |
|---|---|
| **Пилюля** | время и погода; когда что-то происходит — «живая активность»: музыка (эквалайзер и строка песни), таймер/помодоро с кольцом, уведомления. Колесо мыши над пилюлей переключает активности |
| **Анимация** | настоящая пружинная физика (`Spring.cs`): остров «тянется», открывается с овершутом и приземляется с пружинкой |
| 🏠 Главная | скриншот области / экрана, текст с экрана, чистый текст, скрыть значки стола, мини-плеер, часы, уведомления |
| 🎵 Музыка | любой плеер из системного медиацентра Windows (Spotify, Яндекс Музыка, браузеры, AIMP…), перемотка, обложка, слова с подсветкой строки — [LRCLIB](https://lrclib.net) |
| ☀️ Погода | город + Enter; ощущается как, влажность, давление, ветер, УФ, рассвет/закат, прогноз по часам — [Open-Meteo](https://open-meteo.com), без ключей |
| 💬 Чат | Claude, Gemini, DeepSeek, ChatGPT и др. — войти один раз, ключи не нужны; открывается окном под островом |
| ⏱ Таймер | таймер, помодоро (25/5), секундомер |
| 📋 Буфер | 30 последних текстов/картинок/файлов (только в памяти; пароли из менеджеров паролей пропускаются), инструменты текста: регистр, раскладка, транслит |
| 📝 Заметки | Enter — сохранить, Shift+Enter — новая строка |
| 📅 Календарь | напоминания словами (`18:30`, `завтра 9:00 врач`, `через 20 мин чай`) + ваш календарь по секретной ICS-ссылке |
| 🖥 Система | CPU / RAM / GPU, батарея, быстрые ссылки в параметры Windows |
| ⚙️ Настройки | 6 персонажей, 10 цветов, тема, режим «У края», открытие по клику, автозапуск |
| 📷 Скриншоты | выделение области → редактор (ручка, маркер, ластик) → **распознать** (локально, Windows OCR) → **перевести** → копировать/сохранить в `Изображения\Ostrovok` |
| **Персонаж** | рисуется «от руки» (12 кадров/с, дрожащий контур), следит за курсором, моргает, танцует под музыку, спит, думает во время чата; клик — случайная эмоция из семи |

## Горячие клавиши

| | |
|---|---|
| `Ctrl+Alt+I` | спрятать / показать |
| `Ctrl+Alt+O` | открыть остров |
| `Ctrl+Alt+S` | скриншот области |
| `Ctrl+Alt+T` | тёмная ↔ светлая тема |

Управление мышью: наведение (или клик) — открыть, перетащить — переместить, потянуть вверх — спрятать, правый клик — меню.
В редакторе скриншота: `Ctrl+Z`, `Ctrl+C`, `Ctrl+S`, `Esc`.

## Чего нет по сравнению с Atoll

Не реализовано: запись экрана, командная строка `Alt+Space`, полка для файлов, FPS в играх, статус Discord/микрофона/камеры,
загрузки, пункт управления (Wi-Fi/Bluetooth), Claude Code на острове, автообновление, 7 языков (интерфейс только русский),
15 персонажей (у меня 6).

Известные ограничения:
- **Уведомления Windows** (Telegram, Discord…) читаются через `UserNotificationListener`. Windows часто запрещает это
  приложениям без пакета MSIX — тогда остров показывает только свои уведомления (таймеры, напоминания, скриншоты).
  Причина пишется в `%APPDATA%\Ostrovok\log.txt`.
- «Не беспокоить» Windows не позволяет включать из обычной программы: кнопки «Фокус» открывают параметры и ставят напоминание.
- Повторяющиеся события календаря (RRULE) не раскрываются — видны только записанные в ICS вхождения.
- Поверх игр в «эксклюзивном полноэкранном» режиме ничего показать нельзя — остров прячется сам.

## Приватность

Телеметрии нет. Наружу идут только запросы функций, которые вы видите: погода (open-meteo.com, город),
слова песен (lrclib.net, название и исполнитель), перевод (translate.googleapis.com — только по нажатию «Перевести»),
чат (сайт выбранного ИИ), календарь (ваша ICS-ссылка). OCR, буфер и скриншоты работают локально.
Настройки и заметки — в `%APPDATA%\Ostrovok`.
