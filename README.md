# Островок

**«Островок» в стиле Dynamic Island для Windows** — мягкий пружинистый остров наверху экрана.
Музыка со словами песен, погода, таймеры, скриншоты с распознаванием и переводом текста, чат с ИИ,
буфер обмена, заметки, календарь, почта, Telegram, наушники с зарядом, уведомления и маленький персонаж, который живёт в пилюле.

## Возможности

| | |
|---|---|
| **Пилюля** | В свёрнутом виде показывает время и погоду. Когда что-то происходит, превращается в «живую активность»: музыка (эквалайзер и строка песни), таймер или помодоро с кольцом прогресса, уведомление. Колесо мыши над пилюлей переключает активности |
| **Анимация** | Пружинная физика: остров тянется, открывается с мягким овершутом и приземляется с пружинкой |
| 🏠 Главная | Скриншот области или экрана, текст с экрана, чистый текст, скрыть значки рабочего стола, мини-плеер, часы, уведомления |
| 🎵 Музыка | Любой плеер из системного медиацентра Windows (Spotify, Яндекс Музыка, браузеры, AIMP и другие). Круглые кнопки в стиле Apple, перемотка как на YouTube: клик или перетаскивание по полосе ставит нужную секунду, при наведении видно время. Обложка, слова песен с подсветкой текущей строки |
| ☀️ Погода | Город и Enter: ощущаемая температура, влажность, давление, ветер, УФ-индекс, рассвет и закат, прогноз по часам |
| 💬 Чат | Claude, Gemini, DeepSeek, ChatGPT и другие нейросети. Достаточно один раз войти в аккаунт, ключи не нужны |
| 📧 Почта | Gmail, Mail.ru, Яндекс, Rambler, iCloud, Yahoo и другие по IMAP. Добавьте свой ящик, и новые письма (отправитель и тема) появятся во вкладке и на острове. Нужен пароль для приложений, его создание подсказывает окно подключения |
| ✈️ Telegram | Отдельная вкладка: вход по QR-коду, сообщения приходят на остров, даже когда окно Telegram закрыто, счётчик непрочитанных на вкладке |
| 🎧 Наушники | При подключении Bluetooth-наушников остров показывает название и заряд, предупреждает о низком заряде. Заряд виден во вкладке «Система» |
| ⏱ Таймер | Таймер, помодоро (25/5), секундомер |
| 📋 Буфер обмена | 30 последних текстов, картинок и файлов (хранятся только в памяти, пароли из менеджеров паролей пропускаются). Инструменты текста: регистр, исправление раскладки, транслит |
| 📝 Заметки | Enter — сохранить, Shift+Enter — новая строка |
| 📅 Календарь | Месячная сетка: дни с событиями обведены кружком, сегодняшний день залит цветом, по клику на день — список его событий. Вставьте секретную ссылку iCal вашего Google, Outlook или Яндекс календаря — и события (в том числе повторяющиеся) появятся на острове с напоминанием за 10 минут. Свои напоминания пишутся обычными словами: `18:30`, `завтра 9:00 врач`, `через 20 мин чай` |
| 🖥 Система | Нагрузка CPU, RAM, GPU, заряд батареи, быстрый переход в параметры Windows |
| ⚙️ Настройки | 7 персонажей, 10 цветов, тёмная и светлая тема, «стеклянный» вид (сочетается с любой темой), режим «У края», открытие по клику, автозапуск |
| 🧩 Вкладки | Показать или скрыть любую вкладку, поменять порядок, выбрать, какие уведомления показывать на острове, убрать погоду или персонажа из пилюли |
| 📷 Скриншоты | Выделение области, редактор (ручка, маркер, ластик), распознавание текста, перевод, копирование и сохранение в `Изображения\Ostrovok` |
| **Персонаж** | Рисуется «от руки» с дрожащим контуром. Следит глазами за курсором, моргает, танцует под музыку, засыпает, думает, пока вы пишете ИИ. Клик по персонажу показывает одну из семи эмоций |

## Управление

| Действие | Что происходит |
|---|---|
| Навести мышь (или кликнуть) | Остров раскрывается |
| Убрать мышь | Остров сворачивается |
| Перетащить | Остров переезжает и запоминает место; у верхнего края и у центра экрана он «прилипает» на штатное место |
| Правый клик → «Спрятать» или `Ctrl+Alt+I` | Остров прячется |
| Правый клик | Меню: спрятать, тема, настройки, выход |
| Колесо мыши над пилюлей | Переключение активностей |
| Клик по персонажу | Случайная эмоция |

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl` + `Alt` + `I` | Спрятать или показать остров |
| `Ctrl` + `Alt` + `O` | Открыть остров |
| `Ctrl` + `Alt` + `S` | Скриншот области |
| `Ctrl` + `Alt` + `T` | Тёмная или светлая тема |

В редакторе скриншота: `Ctrl+Z` — отменить, `Ctrl+C` — копировать, `Ctrl+S` — сохранить, `Esc` — закрыть.

## Скачать

Готовая программа лежит в разделе Releases: скачайте `Ostrovok-win-x64.zip`, распакуйте и запустите `Ostrovok.exe`. Ничего устанавливать не нужно.

## Требования

- Windows 10 (версия 2004 и новее) или Windows 11, 64-бит
- Microsoft Edge WebView2 Runtime для вкладки «Чат» (в Windows 11 уже установлен)

## Сборка из исходников

Нужен .NET 8 SDK.

```
dotnet run -c Release
```

Готовая сборка, в которую уже включён .NET:

```
dotnet publish -c Release -r win-x64 --self-contained true -o publish
```

Запустите `publish\Ostrovok.exe`. Windows может показать окно SmartScreen, потому что программа не подписана платным сертификатом: нажмите «Подробнее» → «Выполнить в любом случае».

## Особенности

- Уведомления других программ (мессенджеры) показываются, если Windows разрешает приложению их читать. Свои уведомления (таймеры, напоминания, скриншоты) работают всегда.
- Режим «Фокус» Windows нельзя включить из обычной программы: кнопки открывают параметры системы и ставят напоминание на конец.
- Почта: Outlook, Hotmail и Live не поддерживаются, потому что Microsoft отключил вход по паролю для сторонних программ.
- Telegram работает через Telegram Web в фоновом окне (около 150 МБ памяти) и только пока запущен остров. В Telegram Web нужно разрешить уведомления.
- Заряд наушников виден, только если они сообщают его Windows.
- Поверх игр в «эксклюзивном полноэкранном» режиме ничего показать нельзя, поэтому остров прячется сам. Для игр лучше выбирать «оконный без рамки».

## Приватность

Телеметрии нет. Наружу уходят только запросы функций, которыми вы пользуетесь:

| Функция | Куда | Что отправляется |
|---|---|---|
| Погода | open-meteo.com | Город и координаты |
| Слова песен | lrclib.net | Название трека и исполнитель |
| Перевод | translate.googleapis.com | Распознанный текст, только по нажатию «Перевести» |
| Чат | Сайт выбранной нейросети | То, что вы пишете сами |
| Календарь | Ваша ICS-ссылка | — |
| Почта | Сервер вашей почты (например, imap.gmail.com) | Адрес и пароль для приложений, только для проверки новых писем |
| Telegram | web.telegram.org | Всё, что вы делаете в Telegram Web |

Распознавание текста, буфер обмена и скриншоты работают локально. Настройки и заметки хранятся в `%APPDATA%\Ostrovok`, пароли почты — там же в зашифрованном средствами Windows виде, вход в чаты — в `%LOCALAPPDATA%\Ostrovok\WebView2`.

## Полка, телефон и загрузки (v1.1.0)
- **🗄 Полка** — файлы можно перетаскивать на вкладку и дальше в любое окно. Хранятся в `%LOCALAPPDATA%\Ostrovok\Shelf`.
- **📱 Телефон по QR** — по желанию включается маленький локальный сервер. Работает только в вашей Wi-Fi сети, доступ по длинной случайной ссылке; выключен по умолчанию. Windows может спросить про сетевой доступ.
- **⬇ Загрузки в острове** — пока браузер качает файл в «Загрузки», в пилюле видно имя и скорость (отключается в «Полке»).
- **Главная**: плеер со словами, громкость, док приложений, QR-код, пипетка, команда, запись экрана (через «Ножницы»).
